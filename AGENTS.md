# Preclone

Para solicitudes de clonación de repositorios públicos de GitHub, usa la skill `revisar-antes-de-clonar` y llama a `preclone.clonar_protegido`. Para revisión sin clonación, llama a `preclone.revisar_markdown`. Una revisión incompleta, la cancelación o la falta del MCP detienen la operación.
